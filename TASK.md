Goal: Build a modern React-based SQL editor for ClickHouse that makes writing, understanding, and executing SQL queries easier for engineers and data scientists.
- SQL Editor — Write and execute SQL queries with syntax highlighting.
- Results Table — Display query results in a structured table.
- Data Visualization — Bar and Line charts for query results.
- Data Export — Export results to CSV/JSON.
- Activity Log — Query history with execution status, errors, and duration.
AI SQL Assistant

An optional AI assistant with an On/Off toggle that helps users write, fix, explain, and improve SQL queries.

Quick actions: Generate, Fix, Explain, Improve.

Designed to be lightweight, contextual, and non-intrusive, without lengthy conversations.


SQL remains the primary interface. AI assistance and visualizations are optional tools that reduce cognitive load without interrupting the developer's workflow.
Priorities:
1. Complete all core requirements.
2. Implement a lightweight AI assistant.
3. Focus on polished UX, reliability, and clean React architecture.
Core Vision: Transform a traditional SQL editor into an intelligent workspace that helps engineers understand SQL, not just execute it.
